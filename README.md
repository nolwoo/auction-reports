# auction-reports — 경매물건 분석 리포트

경매지 PDF를 AI로 분석해 만든 부동산 경매물건 리포트 모음입니다.

- `index.html` — `reports/index.json`을 읽어 리포트 목록을 보여주는 페이지
- `reports/report-*.html` — 물건별 리포트
- `reports/index.json` — 목록 데이터 (제목, 요약, 경로, Notion 원문 링크, 생성 시각)

리포트는 AI가 작성한 분석이며, 사실관계(권리관계·시세 등)는 반드시 원자료로 다시 확인해야 합니다.

## 리포트를 추가할 때

- 리포트 화면 아래에 AI 분석 안내 문구가 들어가 있습니다. 새 리포트를 만드는 생성기(auction-server)에도 같은 문구를 넣어야 이후 리포트에도 붙습니다.
- 임차인·세대주 등 **개인 이름은 공개 저장소에 올리기 전에 가려 주세요** (예: 박○○). 기존 리포트는 2026-11에 가렸고, 과거 커밋에는 원래 이름이 남아 있습니다.
